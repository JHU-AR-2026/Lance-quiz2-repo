# WebXR Sinusoidal Tasks

This project implements three Babylon.js WebXR tasks:

1. Change the color of a cube sinusoidally.
2. Change the position of an object sinusoidally.
3. Change the scale of an object sinusoidally.

The project uses Babylon.js and WebXR in AR mode.

## Controls

- A button: Task 1
- B button: Task 2
- Trigger: Task 3
